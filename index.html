ConvoKit Android Maven

This is the public Maven feed for the native ConvoKit Android SDK and Jetpack Compose UI package.

Use https://maven.convokit.app/ as the repository URL, then add app.convokit:convokit-android:0.1.0 and, optionally, app.convokit:convokit-android-ui:0.1.1.
